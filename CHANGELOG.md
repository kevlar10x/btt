## 1.0.0 - 2026-10-27

- First release. Start a message with `btt` and an idea, and Claude picks what to build (a skill, hook, browser extension, game mod, script, app or page), says which and why in one line, then builds and tests it.
- Install with `npx skills add kevlar10x/btt -g`, as a Claude Code plugin with `/plugin install btt --marketplace kevlar10x/btt`, or by uploading `btt.zip` from the release to claude.ai.
- New projects go in `~/Documents/claude projects/<name>` unless your CLAUDE.md names another folder, and you're credited under the name your CLAUDE.md gives.
